# 🛡️ AI Sentinel — Multi-Signal AI Text Detection Platform

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Author](https://img.shields.io/badge/Author-Arvind-indigo.svg)](https://github.com/Arvind208)

**AI Sentinel** is a fast, multi-signal AI text detection platform and REST API designed to evaluate the probability that a piece of text was generated by a Large Language Model (e.g., ChatGPT, Claude, Gemini) or written by a human.

Built with Python, FastAPI, and a modern glassmorphic web interface with **real-time sentence-by-sentence heatmap visualization**.

---

## ✨ Features

- 🎯 **Multi-Signal Detection Engine:** Combines statistical perplexity, sentence burstiness, vocabulary entropy, and AI transition signpost analysis.
- 🌈 **Interactive Sentence Heatmap:** Breaks down input text sentence-by-sentence, highlighting sections by AI probability (Green = Human, Amber = Mixed, Red = AI).
- ⚡ **Blazing Fast (<50ms):** Extremely lightweight algorithmic scoring engine that executes in milliseconds without requiring gigabytes of GPU VRAM.
- 📊 **Comprehensive Metrics:** Calculates Coefficient of Variation (Burstiness), Perplexity Index, Type-Token Ratio (TTR), Flesch Reading Ease, and AI Cliché density.
- 💻 **Dual Interface:** Run both an interactive **Web Dashboard** and a scriptable **Command-Line Interface (CLI)**.
- 🔌 **REST API & Swagger:** Full OpenAPI integration available with interactive Swagger docs at `/docs`.

## 🧠 How AI Detection Works

AI-generated text exhibits measurable statistical signatures that distinguish it from human writing:

```
                      ┌─────────────────────────────────────────┐
                      │            Input Document               │
                      └────────────────────┬────────────────────┘
                                           │
         ┌───────────────────┬─────────────┴───────┬───────────────────┐
         ▼                   ▼                     ▼                   ▼
┌─────────────────┐ ┌─────────────────┐ ┌───────────────────┐ ┌─────────────────┐
│   Burstiness    │ │   Perplexity    │ │ Lexical Diversity │ │   AI Markers    │
│ Sentence rhythm │ │  Predictability │ │  Type-Token Ratio │ │ Cliché density  │
│  and variance   │ │    & entropy    │ │    (vocabulary)   │ │  & signposts    │
└────────┬────────┘ └────────┬────────┘ └─────────┬─────────┘ └────────┬────────┘
         │                   │                     │                   │
         └───────────────────┼─────────────────────┴───────────────────┘
                             ▼
              ┌─────────────────────────────┐
              │ Calibrated Multi-Signal     │
              │ Scoring & Heatmap Engine    │
              └──────────────┬──────────────┘
                             ▼
              ┌─────────────────────────────┐
              │  0–100% AI Likelihood Score │
              │  + Sentence Diagnostic Map  │
              └─────────────────────────────┘
```

1. **Sentence Burstiness (Cadence Variance):** Humans write with natural oscillation—short, punchy sentences followed by longer, intricate thoughts (high burstiness). LLMs produce uniform, steady rhythm (low burstiness).
2. **Perplexity (Predictability & Entropy):** LLMs select words with high conditional probability. Text generated by AI has lower cross-entropy and higher predictability than human prose.
3. **Lexical Diversity:** Measures the vocabulary richness using Type-Token Ratio (TTR) and Root TTR (Guiraud's Index).
4. **AI Marker Analysis:** Scans for overused transition patterns and buzzwords frequently overrepresented in AI responses (*"delve", "testament", "seamlessly", "intricate tapestry", "in conclusion"*).

## 🚀 Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/Arvind208/ai-text-detector.git
cd ai-text-detector
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Launch the Web Application
```bash
python app.py
```
Open your browser and navigate to **[http://localhost:8000](http://localhost:8000)**.

---

## 🖥️ Command-Line Interface (CLI)

You can run detections directly in your terminal:

```bash
# Analyze a text string
python app.py --text "In the rapidly evolving realm of artificial intelligence, machine learning stands as a testament..."

# Analyze a file
python app.py --file path/to/document.txt

# Specify custom port
python app.py --serve --port 8080
```

## 📡 REST API Documentation

AI Sentinel exposes RESTful endpoints for integration into third-party apps, moderation bots, or LMS platforms.

### Analyze Text
- **Endpoint:** `POST /api/detect`
- **Headers:** `Content-Type: application/json`
- **Request Body:**
```json
{
  "text": "Yesterday I sat at the coffee shop wondering why my code crashed. It was just a missing comma!"
}
```

- **Example Response:**
```json
{
  "score": 12,
  "verdict": "Likely Human-Written",
  "verdict_level": "human",
  "summary": "This text displays natural linguistic variation, high burstiness, and authentic human cadence.",
  "metrics": {
    "burstiness": 0.82,
    "burstiness_label": "High (Human)",
    "perplexity": 68.4,
    "perplexity_label": "High Entropy (Human)",
    "ttr": 0.81,
    "reading_ease": 74.2,
    "word_count": 21,
    "sentence_count": 2,
    "ai_markers_count": 0,
    "detected_markers": []
  },
  "sentences": [
    {
      "sentence": "Yesterday I sat at the coffee shop wondering why my code crashed.",
      "score": 15,
      "label": "Likely Human",
      "color": "green",
      "reason": "Natural cadence and human variance",
      "word_count": 12
    }
  ]
}
```
